# なかやま商店街 デジタルガイドマップ

公開URL: **https://lightaim-hub.github.io/nakayama-guidemap/**

なかやま商店街（仙台市青葉区）の公式手描きガイドマップをデジタル化したもの。
公式マップ画像を土台に各店舗へ透明クリック領域を重ね、タップで店舗情報
（カテゴリ／子供の声コメント／店舗サイトリンク）を表示。カテゴリ強調・スマホ対応。

## 編集方法

`index.html` 先頭の `STORES` 配列を編集するだけ：

```js
{ name:"店名", cat:"medical", url:"https://...", x:55.6, y:22.0,
  voices:[ {text:"子供の声", who:"小2・ゆうと"} ] },
```

- `cat`：`medical`(健康美容医療) / `life`(生活日用企業) / `food`(食) / `edu`(保育教育)
- `url`：店舗サイト。未定は `"#"`（「サイト準備中」と表示）
- `x,y`：マップ画像上の位置（0〜100%・画像左上=0,0／右下=100,100）
