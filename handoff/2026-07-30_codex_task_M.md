## M-1 実行時に固定UIを避ける

**ビルダーに地図座標を焼かないでください。** 画面サイズで変わるので、
`layoutLabels()` の中で**実行時に**固定UIの矩形を読んで避けます。

```js
// 固定UI (position:fixed かつ表示中) の矩形を集める。#viewport と重なる部分だけが
// 実際に地図を覆う。表示域の外に出ているぶんはクリップされるので無関係。
const keepOut = ['#listbtn', '.zoomctl', '#editbar', '#srcinfo']
  .map(q => document.querySelector(q))
  .filter(e => e && getComputedStyle(e).position === 'fixed'
                 && getComputedStyle(e).display !== 'none')
  .map(e => e.getBoundingClientRect());
```

- ラベルの候補位置を評価するとき、**その候補の描画矩形が keepOut のどれかと 1px 以上重なるなら
  その候補を落とす**（`#viewport` の矩形でクリップしたうえで判定）
- 既存の候補集合（2方向 × 8距離 × 21縦位置 = 336通り）の中から、重ならないものを選ぶ
- どの候補も重なる場合だけ**非表示**にする
- `layoutLabels()` はズーム時にも走るので、ズームしても規則が効くこと
