## N-1 こどもの声バッジを自分の★の隣に付ける（N18）

現在 `template.html:781` で `translate(bx,by)` に置かれ、**★から約17.5m（地図単位固定）**
離れています。隣の店は8.4mまで近づけるので、**4件が他店の★のほうに近い**状態です。

```
レストラン KAYA    の声バッジ → BURB usedclothing の★のほうが近い (自分16px / 相手11px)
Double Egg5丁目  の声バッジ → おたからや           (自分16px / 相手10px)
フラワー中山       の声バッジ → 中山鍼灸接骨院       (自分16px / 相手14px)
柏屋             の声バッジ → フラワー中山         (自分16px / 相手13px)
```

こどもの声は**本企画の中核機能**です。持ち主を取り違えるのは致命的です。

- バッジの大きさを**画面px固定**にする（★7.2〜11px に対し **12〜14px 程度**。
  ★より少し大きい程度に収め、3.27倍のような差をなくす）
- 位置も**画面px固定のオフセット**で自分の★の隣に置く（★の縁から 2〜4px）
- **ハード制約: どのバッジも、自分の★までの距離が他のどの★までの距離より短いこと**
- ★・ラベルと重ならないこと（`bbox交差 0` を維持）

## N-2 信号アイコンを★・ラベルと重ならないようにする（N19）

`template.html:412-417` で 22×11 の地図単位固定。道路幅13mの1.68倍で、どのズームでも
通りより太いままです。カットショップ NOBU の★とラベルに重なっています。

描画順は `gRoads`（信号）→ `gShops`（★/ラベル）なので、**隠れるのは信号のほう**です。
店は読めますが、N6 で「歩く時の目印」として使う信号が読めなくなります。

- 信号アイコンも**画面px固定**にする（道路の描画幅と連動させる。
  `幅 = clamp(14, 1.4 × 道路main描画px, 26)` 程度を目安に）
- **★やラベルと重なる場合は、信号を道路に沿って少しずらしてよい**
  （ただし交差点から20m以内は維持すること。N6 が「信号が交差点に立っている 13/13」を見ています）
- 信号の座標は OSM 実データです。**削除・追加はしないこと**（13基のまま）
