## 機能1: デジタルスタンプラリー
**localStorage**: key `naka_stamps_v1` = 訪問店名(name)の配列。

### UI
- **ポップアップにボタン追加**（"お店を見る" の下）: `<button id="popupStamp" class="stamp-btn">`。
  - 未取得: テキスト「✓ 来たよ！スタンプGET」、押すと name を localStorage に追加。
  - 取得済: テキスト「⭐ スタンプGET済み」、`disabled` 風スタイル（再タップで取消も可: 押すと解除→未取得表示。トグル）。
  - showPopup 内で現在店 `s` を参照して状態とクリック挙動を設定。
- **進捗バナー**（header 直下に設置・`.stamp-bar`）: 「🗺 スタンプ {n}/47」＋プログレスバー＋バッジ名。
  - バッジ: 0=「探検スタート」/1-4「みならい探検隊」/5-14「たんけん隊」/15-29「なかやま博士」/30-46「街マスター」/47「🏆全店制覇！」。
- **訪問マーク**: 訪問済み店は 地図 `.hit` に `.stamped` 付与（`::after` で小さな⭐）＋ 店舗リスト行 `.srow` に⭐表示。
- **スタンプ帳モーダル**: バナー内に「📖スタンプ帳」ボタン→モーダル(`.stampbook`)。全47店を一覧（訪問=⭐/未訪問=○・カテゴリ色）。「ぜんぶ消す」リセットボタン（confirm 付）。
- **renderStamps()** 関数を1つ作り、バナー/地図マーク/リストマーク/モーダルを毎回まとめて再描画。スタンプ増減時に必ず呼ぶ。

## 機能2: 子供の声を地図に常時表示（巡回バブル）
- `voices.length>0` の店（約12店）を対象に、地図上へ手描き風吹き出し `.mapbubble` を表示。
- **巡回**: 同時表示は最大3個。4秒ごとにフェードで次の3店へローテーション（`setInterval`）。`prefers-reduced-motion` 時は巡回停止し先頭3個を静止表示。
- 位置: 店の x% , y% を基準に上へ約3%オフセット。`map-wrap` 内に収まるよう left を clamp（はみ出し防止）。
- 中身: 先頭 voice の text（長い場合は省略, 例 全角14字+…）。`.voice` 既存スタイルに準じた紙色・角丸・小さな尻尾。
- クリックで該当店の showPopup を開く（`pointer-events:auto`）。装飾的だが操作可。
- スマホ(≤430px)では同時2個・フォント小に。地図のクリック領域(hit)を覆い隠してタップを妨げないこと（バブルは voice 店の上側に小さく）。

## 機能3: 季節演出
### 季節レイヤー `.season-layer`（map-wrap 内・pointer-events:none・控えめ）
- `getSeason()`: 月で判定 3-5春 / 6-8夏 / 9-11秋 / 12-2冬。
- 装飾（CSSアニメ・要素数は各6-10個程度・opacity低め・ゆっくり）:
  - 春: 🌸 花びらが舞う / 夏: 🎋⭐ 七夕飾り / 秋: 🍁 紅葉が舞う / 冬: ❄️ 雪＋⛄。
- 手描きの温かみを壊さない＝大きすぎ・多すぎ・派手な色は禁止。地図の視認を妨げない。

### イベントカウントダウン帯 `.event-ribbon`（地図の上）
- **日付を捏造しない**。確定情報のみ使用:
  - 七夕まつり = **8/6-8**（手描きマップ記載）。
  - 街道市 = **毎月第3土曜**（マップ記載・JSで第3土曜を算出＝確定）。
  - スノーマンまつり/街道市まつり10月 等の正確な「日」は不明 → カウントダウンに使わない（「冬開催」等の表記に留め日数は出さない）。
- 直近の確定イベント（七夕8/6 と 今月/来月の第3土曜のうち近い方）を「🎏 {名称} まで あと{n}日」と表示。当日は「本日開催！」。
- 既存日付に不確実性がある催事は日数表示しない。

### 表示ON/OFF
- 帯の端に小さな「🎨」トグル（装飾レイヤーの表示/非表示）。`localStorage naka_deco` に保存。デフォルトON。

## 共通・厳守
- 既存の `const STORES`（name/cat/url/x/y/voices）は不変。新機能は同配列を読むだけ。
- 既存のフィルタ・店舗リスト・ポップアップ位置計算を壊さない（回帰させない）。
- 横スクロールを発生させない。`map-wrap` の `overflow:hidden` を尊重（バブル/装飾は内側）。
- 追加CSSは既存テーマ変数（--bg/--ink/--paper/--line/--c-*）を流用し世界観を統一。
- JS構文エラーゼロ。グローバル汚染を最小に。

## やらないこと（本v1スコープ外）
- 子供の声「投稿」フォーム（承認フロー要・振興組合連携後）
- QR/合言葉によるスタンプ解錠（正直ベースのチェックインのみ）
- ピンチズーム・検索・タグ等（別Issue）
