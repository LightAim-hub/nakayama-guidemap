# BQ: このマップが「世界について主張していること」のうち、誰も検証していないものを洗う

これは**実装の依頼ではない。監査の依頼**。コードは1行も変えないこと。

## なぜ

今日、方位記号の針が **92.8度ずれたまま本番に出ていた**ことが、商店街の担当者からの指摘で分かった。

```js
// 投影は rot_deg だけ回してあるので、その分だけ戻す。   ← このコメントが間違っていた
needle.setAttribute('transform', 'rotate(' + (-rot) + ' 22 22)');
```

コード単体では筋が通って見え、コメントが誤りを裏書きしていた。
**`gate.py` に「針が北を向いているか」という項目が無かったので、誰も気づけなかった。**

同じ形が今月すでに3回起きている:
1. `gate.py` の総なめが **320px 幅を見ていなかった**（手順書には「必ず320pxで検証」と書いてある）
2. 総なめが **端末の文字サイズを一度も変えていなかった**（200%で見出しが刈られていた）
3. **方位記号の向き**（今回）

いずれも「コードのバグ」ではなく **「検査に項目が無い」**。差分を読むレビューでは出ない種類。

## 依頼

**この製品が利用者に対して主張している事実を全部数え上げ、そのうち何が検証されていないかを出す。**

対象（これに限らない。見つけたものは全部）:

- 位置・方角・距離（地図上の座標、二列の東西、「◯m先」「西へ約◯メートル」、縮尺バー、方位記号、引き出し線）
- 数（「全60店」「11店」、絞り込みの件数、検索結果の件数、一覧の総数）
- 時間（「◯月◯日時点」、営業時間、「いま営業中」の判定、定休日）
- 同一性（店名・住所・電話・URL がどの出典から来て、画面のどこに出るか）
- 地物（信号の位置、公園・川・道路の形と名前、参道、出口の案内）
- 状態の言い換え（「押せる」ように見えるもの、読み上げと画面の食い違い、`aria-label` による上書き）

## 出し方（この形以外で返さない）

| # | 主張していること | 画面のどこ | 正しさの出どころ | いま検証されているか | 検証する方法 | 危険度 |
|---|---|---|---|---|---|---|

- **「検証されているか」は `gate.py` の N番号で答える。**無いなら「無し」と書く。
  「N40 が近いことを見ている」のような曖昧な書き方をしない。**その項目が、その主張が偽の時に落ちるか**で判断する
- **「検証する方法」は実行可能な粒度で書く。**「目視する」は不可。
  何を測り、何と突き合わせ、どこまでのずれを許すか
- **危険度** = 間違っていた時に利用者が受ける害。高＝道に迷う/店にたどり着けない/嘘の情報を信じる
- **コードのコメントを根拠にしない。**今回の事故はコメントが誤りを裏書きしていたもの。
  必ず `mapdata.json` / `official_details.json` / 投影式 / OSM 由来データなど**元の値**まで遡って確かめる
- 静的解析でよい（この環境ではブラウザを起動できない）。ただし**推測は「未確認」と明記**すること

## 特に見てほしい所

- `tools/v2-build/gate.py` の N1〜N61 を一覧にし、**それぞれが「何が偽の時に落ちるか」**を1行で書く。
  そのうえで、上の表と突き合わせて**穴**を出す
- `tools/v2-build/template.html` の中で、**画面に数字・方角・時刻・件数を出している箇所**を全部拾う
- **同じ値を2箇所以上で別々に計算している所**（今日、画面の距離と読み上げの距離が食い違っていた原因がこれ）
