## AP-1 向かい合わせが1組だけ逆向きにずれている（N42 · 1件）

```
cake NAO と 西原歯科医院 は南北差12m (画面なら15px) の向かい合わせなのに
画面では47px ずれていて 誤差62px (上限24・引き出し線も出ていない) [360x640]
```

誤差62px は「15px ずれているべきところが、**逆向きに47px** ずれている」という意味。
上下の並びが実際と逆に見える。

Task AO の交互射影は「上限47px以内に収める」ことを目標にしているため、
上限に張り付いたところで止まり、**真のズレ（Δy × 1.3px/m）に近づける力が働いていない**。

### 直し方

交互射影の第2段の目標を「47px以内に収める」から
**「真のズレ Δy × STRIP_PX_PER_M に一致させる」**に変える。

```
向かい合う組 (南北差20m以内・別の側) それぞれについて:
  want = (東の実y − 西の実y) × STRIP_PX_PER_M     ← 符号つき
  now  = 東の中心 − 西の中心
  ずれ = now − want
  東を ずれ/2 だけ戻し、西を ずれ/2 だけ戻す
```

これで、詰め込みが許す範囲で真の位置関係に最も近い配置になる。
上限に張り付いて止まることがなくなる。

### 検証（ブラウザ無しでできる）

Node で配置計算を再現し、向かい合う全10組について
`|画面のズレ − 真のズレ|` を出すこと。結果ファイルに表で書く。

- 全組で誤差 **24px 以下**が目標。
- 幾何的に不可能な組（花祭壇の向かいの3枚など）は、
  誤差 **53px 以下**かつ **`displaced` クラスが付いて引き出し線が出ている**こと。
