## T-3 横向きで地図が見えるようにする

いま横向きは**地図が51〜57px（画面の13〜16%）**しかありません。実質、地図が無いのと同じです。

```
640×360   ヘッダ38 + カテゴリ101 + 検索50 + フッタ114 = 303px → 地図 57px (16%)
844×390   ヘッダ89 + カテゴリ101 + 検索50 + フッタ 99 = 339px → 地図 51px (13%)
```

横向きは**横に余裕がある**ので、縦を食っているものを横へ逃がしてください。
たとえばカテゴリと検索を左の列にまとめれば、縦は ヘッダ + フッタ だけになります。

合格: **横向きで 地図が200px以上 かつ 画面の45%以上**
（`640×360` なら ヘッダ38 + フッタ約100 = 138px で地図222px = 62% が取れる計算です）

やり方は任せます。ただし:

- **縦向きのレイアウトは1pxも変えないこと**（N23 の縦向き 52% / 330px は現状で通っている）
- カテゴリ6個は横向きでも**全部見えること**（Task O で「6個中2個しか見えない」を直した）
- 「こどもの声（11店）」は先頭のまま
