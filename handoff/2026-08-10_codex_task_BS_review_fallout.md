## 1【公開停止】方位記号の「北」の文字が針と別方向を指している

```html
<g id="compassNeedle">
  <path d="M22 5 ..." class="compass-north"/>
  <path d="M22 39 ..." class="compass-south"/>
</g>
<text x="22" y="15" class="compass-label">北</text>   ← 回転グループの外
```

針は JS で `rotate(46.4 22 22)` されるが、**「北」の文字は回らないので12時の位置に残る**。
同じ方位記号が「北は右上」と「北は真上」を同時に示していて、**利用者に矛盾した案内を出している**（いま本番に出ている）。

**直し方の指定**: 「北」の文字を**針と一緒に動かす。ただし文字自体は水平のまま**にすること
（46.4度傾いた「北」は読みにくい。利用者は高齢の方を含む）。

実現方法は任せるが、素直なのは文字を `#compassNeedle` の中に入れ、
文字だけ自分のアンカーを中心に逆回転させる（`rotate(-R 22 15)`）方法。
グループの回転と打ち消し合って、**位置は針先側・字は水平**になる。

## 2【公開停止】引き出し線を消したのに、二列の位置ずれが残っている

破線 `.strip-row.displaced::after` を消したが、**ずらして置くこと自体は続いている**。
`gate.py` の N42 は「線が出ているなら実位置が読める」という理由で最大56pxのずれを免除していた。
**線を消した以上その根拠は無いので、免除を外した。** その結果いま **FAIL 2件**:

```
ダイニングバー 祭 と 花祭壇 は南北差9m (画面なら12px) の向かい合わせなのに
  画面では44px ずれていて 誤差32px (上限24) [320x568]
中山不動産 と 花祭壇 は南北差17m (画面なら23px) の向かい合わせなのに
  画面では62px ずれていて 誤差39px (上限24) [320x568]
```

つまり **320px 幅の端末で、向かい合っているはずの店が約25〜30m ぶんずれて見えている**。

**やること**: 誤差を **24px以下**に収める。320x568 で発生しているので、狭い画面の詰め方の問題。

- 手がかり: 花祭壇の向かい側は3枚が縦に積まれる。カードの最低高さ44px（指で押す下限・**下げない**）＋
  隙間8px で 3枚=148px 必要になり、実際の間隔より広くなって押し出されている
- **触ってよいのは詰め方**（カード間の隙間、狭い画面での余白、名前の折り返し方、`layoutStripRows` の詰め方）
- **触ってはいけないのは**: 44pxの指の基準／店の東西・順番（N40/N41）／店名の中身
- **破線を戻して逃げない**（消すのはボスの指示）

どうしても幾何的に24px以下にできない場合は、**何px までしか縮まらないか・何がそれを決めているか**を
数字で `result.txt` に書くこと。勝手に別の見せ方を発明しない。

## 3【中】店の詳細の見出しだけ、文字の上限を無視している

狭い画面（`max-width:759px`）の規則が後勝ちで、基底の `min(1.42rem, var(--heading-font-max))` を
`font-size:1.18rem` が上書きしている。**端末200%で詳細の店名が 37.76px** になる一方、
同じ画面で本文は18pxに抑えられていて釣り合っていない。

`min(1.18rem, var(--heading-font-max))` のように、狭い画面の規則も同じ上限変数を通すこと。
