## J-1 道路の描画幅に画面px の床を入れる（N11）

いま道路は地図単位の実幅で描かれるため、倍率が下がると細くなりすぎます。

```
描画幅 = max(実幅[地図単位], 床[px] / pxPerMeter)
```

床: **main 12px / major 11px / mid 8px / minor 5px**（縁 `-c` は現在の比率を保つ）

- `applyZoom` で倍率が変わるたびに再計算する
- **0.92 px/m 以上では実幅が床に勝つので、歩きズーム(2.0px/m)の描画幅は変わらないこと**
  （検証: main 26.0px / major 24.0px / mid 18.0px / minor 10.0px のまま）
- 実幅そのもの（spine 塗13/縁18・major 12/17・mid 9/12.5・minor 5/7）は**変更しない**

## J-2 ★の大きさを描画された道路幅に連動させる（N12）

```
★の画面px = clamp(6.0, 0.60 × 描画された main 道路のpx, 11.0)
```

- 既定ズーム: 0.60 × 12px = **7.2px**（現在 通常11px / アンカー14px）
- 歩きズーム: 0.60 × 26px = 15.6 → 上限で **11px**（現在と同じ・変えない）
- **下限 6px は絶対**（`MIN_STAR_PX`）。これ未満にして N12 を通すのは不正
- アンカー店（こどもの声あり）は概観では同サイズになる。色・バッジで区別を保つこと
- **★は60件すべて必ず描く**（サイズを0にして消すのは禁止）

## J-4 ラベルの縁から自分の★が明確に最近傍（N14）

可視ラベルは、**矩形の縁から自分の★までの距離が、他のどの★までの距離の 0.80 倍以下**であること
（= 自分の★が他より25%以上近い）。中心でなく**縁**で測ります（長い店名が不利にならないように）。

**直し方の優先順位:**

1. **置き換えて満たす** — 反対側に出す / 引き出し線を短くする / ★の隣に寄せる
2. どうしても満たせないラベルだけ**非表示**にする

J-2 で★が 11px → 7.2px に小さくなるので、ラベルは自分の★により近づけられます。まず配置で解いてください。

**制約: 既定ズームの可視ラベルは 40件以上を維持**（現在44件）。隠して通すのは
40件を割った時点で全体不合格になります。歩きズームは60件（全店）を維持。
