# Task AY — 地図を「歩く人の道具」にする

対象: `tools/v2-build/template.html` のみ。
`gate.py` / `preview.html` / `preview.template.html` / 座標 は触らない。

## この作業の起点（ボスの言葉）

> 一番は地図で見るの方を整えないといけなくて、地図で見るの方を客観的に見て
> 「なんで枠内というか地図が見切れてるんだろう」とか「星がちっちゃくて見にくいな」とか、
> そういうところ、ここから考えられるお客様の声を想定して作りやすくしないと。
> Uber Eats であったり Google マップもそうだけど、そういう地図の UI とかが
> 使われているところって、お客様のことを考えて作ってるやんか。利用者のことを考えて
> 作ってるわけやんか。そういう利用者の声っていうのを考えて作らないとダメだよ。

**数字を通すための作業ではない。歩いている人が困らないようにする作業。**
迷ったら「中山の商店街を初めて歩く人が、これで店にたどり着けるか」で決めること。

## 想定される利用者の声と、今の状態（実測）

| 利用者の声 | 今どうなっているか |
|---|---|
| 「今どこにいるの？」 | **現在地が出ない**。歩く地図で一番効く機能が無い |
| 「押せる場所がわからない」 | ★の見た目 **7.2px** / 当たり判定 44px。**6倍ずれている** |
| 「何屋さんかぱっと見でわからない」 | ★は色分けしてあるが 7.2px では色が判別できない |
| 「地図の下が空いてるのは何？」 | 枠 744px に対して地図 **594px**。下に **150px の空白** |
| 「商店街ってどこからどこまで？」 | 1573m のうち **646m（41%）** しか見えない |

## AY-1 地図が枠を埋める（N52・2件）

```
地図が枠の高さ744px に対して594px しかなく、下に150px の空白がある (枠の80%) [390x844]
地図が枠の高さ826px に対して652px しかなく、下に174px の空白がある (枠の79%) [428x926]
```

原因: SVG が `width:100%; height:auto` で、viewBox の縦横比（424:646）がそのまま
高さを決めているため。枠の縦横比（390:744）と合っていない。

**直し方**: 起動時と画面の向き・大きさが変わったときに、**枠の縦横比に合わせて
初期 viewBox を計算し直す**。地図は常に枠いっぱいに表示される。
中心（今 x=362+424/2, y=677+646/2 あたり）は保ち、足りない方向に広げる。

## AY-2 ★を「指で押すもの」の大きさにする（N12・60件）

```
全60店が ★7.2px しかない (最低14px)
```

**背景を必ず読むこと。** 採点表 N12 は今日 2026-08-01 に基準を書き換えた。

- 元は `★ ≤ 道路幅の0.60倍` で、道路12px から ★7.2px が決まっていた。
  理由は「★が通りより太いと通りを覆う」。**これが誤りだった。**
- Google マップも Uber Eats も、ピンは 20〜30px あって道路に堂々と重なる。
  それで位置が狂わないのは **ピンのアンカー点が正確な位置を指す**から。
  **正確さは印を小さくすることで担保するものではない。**
- 「通りを覆う」は作り手の美意識であって、利用者の困りごとではない。

**やること**: 既定ズームで ★を **14px 以上**にする（上限は道路幅の2.0倍）。
指で押す対象として見える大きさにすること。18px 前後が読みやすいと思われるが、
実際に配置して混み具合を見て決めること。

**絶対に守ること（ボスの受け入れ条件）**:
- **★の中心が通りの帯の外にあること**（N15 の第1段）。
  これが「この店舗はここの向かい側あってるね」の担保。中心が帯に入ったら不合格。
- ★が大きくなると帯に重なるが、それは構わない（上限5.0m に緩めてある）。
  重なっても中心がどちら側かが読めればよい。必要なら★の縁（白い外周）を強くして
  道路の上でも形が読めるようにすること。

★を大きくすると地図が混む。ラベルの配置が苦しくなるはずなので、
**N26（こどもの声11店の名前）・ラベル可視40件以上・bbox交差0** を必ず保つこと。
苦しければラベル側を優先度で間引いてよい（AQ で入れた仕組み）。

## AY-3 「今どこにいるの？」に答える（新規・最優先の利用者価値）

歩きながら使う地図で、これが無いのが一番大きい欠落。

- 地図の下帯（または右下）に **「現在地」ボタン**を置く（44px以上）。
- 押したら `navigator.geolocation.getCurrentPosition` で位置を取り、
  地図に **現在地の印**（Google マップの青い点にあたるもの。この地図の絵柄に合わせた色で）
  を出して、そこへ寄せる。精度が悪いときは円で誤差を示す。
- **勝手に位置を取らない**。押されたときだけ。これは礼儀であり、
  許可を求めるタイミングとして正しい。
- 商店街の範囲外にいるときは「今は中山からXXkm 離れています」と伝えて、
  地図は動かさない（いきなり何も無い所へ飛ばさない）。
- 位置が取れない・断られたときは、静かに元のままにして短く伝える。エラーで壊れない。
- 座標は **どこにも送らない・保存しない**。画面に出すだけ。

## AY-4 「商店街ってどこからどこまで？」に答える（新規）

今は 1573m のうち 646m しか見えない。全体像がつかめない。

- 下帯に **「全体」ボタン**（または現在地ボタンの隣）。押すと商店街の端から端まで
  一望できる viewBox にする。
- そのとき★は小さくなるが、**最低14px は保つ**（保てないなら、その倍率では
  ★を14pxに固定して地図だけ縮める＝画面px固定の印にする）。

## AY-5 何屋さんかが色で読めるようにする

★が14px以上になれば、今のカテゴリ色（医療=白/生活=緑/食=橙/教育=青/名所=青緑）は
判別できるようになるはず。実際に見て判別できなければ、色の差を強めること。
アイコン化は今回はやらない（次の段）。
