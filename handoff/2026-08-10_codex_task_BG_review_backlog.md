## BG-1 🔴 目で見る距離と、読み上げの距離が食い違う

**現象（実測）**: 通りから離れた店のカードで、画面の文字と読み上げが別の数字を言う。

| 店 | 画面の文字 | 読み上げ (`aria-label`) |
|---|---|---|
| ダイシン長命ヶ丘店 | 約650m先 | 通りから西へ約**213**メートル |
| Friend vividhair | 約1.4km先 | 通りから東へ約**147**メートル |
| 工房しらかば | 西へ約574m | 通りから西へ約574メートル（一致）|

**原因**: `template.html` `makeStripRow()`。
`aria-label`（3168-3169行あたり）は常に `entry.distance`（通りからの直角距離）を使うが、
見えている `.strip-distance` は 400m 以上の店だけ `entry.s.far_m`（本当の距離）に切り替えている。
2026-08-04 に見える側だけ直して、読み上げ側が取り残された。

**直し方**: `distText` を先に組み立て、**同じ文字列を `aria-label` にも使う**。
数字を2箇所で計算しない（それが今回の原因）。

**合格**: 通りから離れた全カードで、`.strip-distance` の文字列が
そのカードの `aria-label` にそのまま含まれている（0件の食い違い）。

## BG-2 🔴 お店一覧を読み上げると、店名しか読まれない

**現象（実測）**: `#listrows` の行は画面に「Friend vividhair / 泉区 南中山2-17-4 南中山中学校隣」と
種類のアイコンつきで出ているのに、`aria-label` が `"Friend vividhair"` だけ。
`aria-label` は中の文字を**置き換える**ので、読み上げでは住所も種類も消える。

**原因**: `template.html` 4600行あたり
`b.setAttribute('aria-label', s.name + ((s.voices||[]).length ? '、こどもの声あり' : ''));`

**直し方**: 種類（`CATS[s.cat]` の表示名）と住所（画面に出しているのと同じ整形後の文字列）を足す。
並びは画面と同じ順（種類 → 店名 → こどもの声 → 住所）にする。
アイコン `.ldot` は `aria-hidden` のままでよい（種類は文字で読まれるため）。

**合格**: 一覧の全行で `aria-label` に 種類 と 住所 が入っている。
画面に出ている文字で、読み上げに出ないものが無い。

## BG-3 こどもの声で絞り込んだのに、開いた店の声が閉じている

**現象（実測）**: こどもの声チップを押す → 絞られた店を押す →
詳細シートの声は `button.detail-status.voice[aria-expanded="false"]`、
`.detail-voice-block` は高さ0。**声を読みに来た人が、もう一度押さないと読めない。**

**直し方**: 声で絞り込んでいる状態（`voiceOnly`）から開いた詳細に限り、声を最初から開く。
絞り込んでいない時の既定は**今のまま閉じる**（勝手に長くしない）。
`aria-expanded` と実際の表示を必ず一致させる。

**合格**: 声チップON → 店を開く → `aria-expanded="true"` かつ声の本文が見えている。
声チップOFF で開いた時は今までどおり閉じている。

## BG-4 地図を見ている時に、絞り込みに手が届かない

**現象（実測）**: `body.map-open` の間、`#filters` は `visible:false / height:0`。
今の絞り込みを示す `#mapFilterBadge` は出るが、**押せない（`role="status"` の表示専用）**。
種類を変えたい人は一度「通りへ」戻るしかない。

**直し方**: 地図画面から絞り込みに到達できるようにする。**新しい画面を作らない**のが条件。
既にある `#mapFilterBadge` を押せるものにして、押したら絞り込みチップの列を
地図の上に重ねて出す（もう一度押す / Esc / 外側を押す で閉じる）のがいちばん小さい変更。

- 押せる大きさは 44px 以上（N43）
- 出している間、地図の当たり判定と重ならない（N44）
- 絞り込んでいない時も「絞り込み」と分かる文字を出す（今は空だと消える）
- 地図画面の下帯（お店一覧・通りへ）の面積を増やさない

**合格**: 地図表示のまま種類を変えられる。gate の N43 / N44 / N45 / N49 が違反0のまま。

## BG-5 最初の画面に「全部で何店あるか」が無い

**現象（実測）**: 開いた画面の文字に `60` が出てこない。
出ているのは「こどもの声（11店）」だけで、これを全店数だと読み違える。
詳細シートには「3件目 / 60件」と出ているので、**数字は持っているのに入口で言っていない**。

**直し方**: 見出し（`header h1` の下）か通り沿いの案内文に「全60店」を出す。
**数は `GEO.shops.length` から出す**（固定文字で書かない。閉業でまた変わる）。

**合格**: 開いた瞬間の画面に全店数が出ている。320px幅・`html{font-size:24px}` でも枠外に出ない（N28/N29）。

## BG-6 共有URLで来ると、読み上げの位置が「通りへ」ボタンに残る

**現象（実測）**: `?shop=工房しらかば` で開くと、
画面は正しい（地図が開き・印に輪・詳細シートに工房しらかば）が、
`document.activeElement` が `#mapbtn`（「通りへ」）。
**読み上げの人は「通りへ、ボタン」と言われ、自分がどの店を見ているか分からない。**

**直し方**: `?shop=` から開いた時は、開いた詳細（`#detailPanel` の見出し）に読み上げの位置を移す。
通常のタップで開く時の挙動は変えない。

**合格**: `?shop=` 付きで開いた直後の `document.activeElement` が詳細シートの中にある。
Esc で閉じた時の戻り先が壊れていない（N33）。

## BG-7 「◯年◯月◯日時点」が1つしかなく、実際より古い

**現象**: `mapdata.json` の `meta.info_as_of` は `"2026年6月12日"` の1つきりで、
**こどもの声**（6月12日に集めたもの）と**店舗情報**（2026-08-04 に公式サイトから取り込んだ
電話・営業時間・定休日）の両方に同じ日付を出している。
店舗情報のほうは 8月4日時点なので、**2か月古く見せている**。

**直し方**: `build_mapdata.py` に `VOICES_AS_OF`（= 2026年6月12日）と
`DETAILS_AS_OF`（= 2026年8月4日 / `official_details.json` を取り込んだ日）を分けて持ち、
`meta` に両方入れる。表示側は出どころごとに使い分ける:

| 出ている場所 | 使う日付 |
|---|---|
| こどもの声の但し書き（3759行）| `voices_as_of` |
| 振興組合の掲載情報の但し書き（3858行）| `details_as_of` |
| 画面下の「このマップの情報は…」（933/935行）| `details_as_of` |

`info_as_of` は消さずに残す（他から参照されている場合の保険）。**日付を推測で書かない。**

**合格**: 声の但し書きが6月12日、店舗情報の但し書きが8月4日。両方が画面で読める。
