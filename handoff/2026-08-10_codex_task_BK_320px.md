## なぜ今出てきたか

手順書は「**320px幅で必ず検証する**」と言っているのに、`gate.py` の `UI_DEVICES` は
**360px からしか見ていなかった**（N20〜N35 / N43〜N49 / N57 / N58 が全部 320px を素通り）。
実機の絵を目で見て「地図で見 / る」「（11店 / ）」に気づき、端末を足したら6件出た。

**6件とも `83c260a` の時点で既に存在する**（今日の作業で入れた退行ではない）。実測で確認済み。

- 下の帯: `お店一覧` ／ `地図で見` + 改行 + `る`

## 直し方の方針

**320px で入る形にする**。数を減らしたり文言を変えたりする前に、まず入れ物側で解く。

- 文字を小さくする / 余白を詰める / チップの列を組み直す / `word-break:keep-all` を効かせる
- **閉じ括弧「）」を行頭に置かない**（この規則は台帳 §5 に「未対応」として載っているもの）
- 数字の部分は `（11店）` のまま。**中身の言い回しを勝手に変えない**
- N23 は「主の内容の高さ」が床に届いていない。固定UI（見出し・下帯・絞り込み）の
  合計の高さを 320×568 で削って主の内容に 330px 以上を渡す
