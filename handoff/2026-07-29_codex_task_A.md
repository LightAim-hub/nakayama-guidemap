### 画像最適化

`assets/photos/` へ出力。WebP（幅1200・品質80・各120KB以下）＋ JPEG fallback（同幅・品質78）。
Pillow が使える（ImageMagick は未インストール）。変換スクリプトは `tools/make_photos.py` として残し、べき等に（`tools/make_qr.py` と同じ思想）。

### データ

`GEO.shops[i]` に `photos` を追加（`voices` と同じ並びに置く）:

```json
"photos":[
  {"src":"assets/photos/tobinoko_1","alt":"なかやまとびのこ公園の東屋とすべり台"},
  {"src":"assets/photos/tobinoko_2","alt":"なかやまとびのこ公園の小川"}
]
```

`src` は拡張子なしで持ち、`<picture>` 側で `.webp` / `.jpg` を組み立てる。alt は上表の「内容」を日本語で自然文にすること（読み上げ対応）。

### UI — 掲載位置はあみさん指定

**店名 `<h2>` の直後・`statuses`（「こどもの声◯件を見る」バッジ）の直前**に挿入する。
あみさんのスクショで赤矢印が指している位置がここ。現行 `buildDetailCard()` の組み立て順は
`カテゴリ → 店名 → statuses → note → 声 → リンク` なので、`statuses` を append する前に写真ブロックを append する。

形式は **viewer-first**（少数枚の定石）:

- メイン画像1枚をカード幅いっぱい（アスペクト16:9・角丸・`object-fit:cover`）
- その下にサムネイル2つ（44px以上のタップ領域）。タップでメイン画像を差し替え
- メイン画像タップで lightbox 拡大。**Esc と ✕ で閉じ、閉じたらフォーカスを元のボタンへ戻す**（既存モーダルの作法に合わせる）
- `loading="lazy"` `decoding="async"`
- 写真が1枚だけの地点はサムネ列を出さない

**⚠️ 横スクロールのカルーセルにはしないこと。** 詳細パネル自体が横スワイプで店を送る作りなので、ジェスチャが競合する。サムネはタップ切替のみ。

**⚠️ DOM生成は `createElementNS`/`createElement` + `textContent` で行う。** このファイルは過去に `innerHTML` を全廃してXSS対策済み。`innerHTML` を復活させない。

## ③「坂の上からの景色」地点の追加

`GEO.shops` に1件追加する。**座標は推定ではなく国土地理院DEMの実測**（バス通り上の標高プロファイルを取り、頂上を特定した）:

```json
{
  "name": "中山の坂の上",
  "cat": "place",
  "url": "#",
  "voices": [],
  "note": "バス通りでいちばん高いところ（標高155m）。ここから南へ下る坂が「中山の坂」で、坂の上からは市街地が見渡せます。",
  "addr": "",
  "lat": 38.294850,
  "lng": 140.836401,
  "src": "gsi_dem",
  "x": 427.8,
  "y": 270.0,
  "padr": 22,
  "photos": [{"src":"assets/photos/sakanoue_1","alt":"中山の坂の上から見た市街地の眺め"}]
}
```

裏付け（作業判断の材料・実装には不要）: バス通りの標高は y=270 の155mが頂上で、南端 y=1585 の69.1mまで単調に下る（高低差86m）。紙マップであみさんが赤丸で示した位置（東北電力研究開発センターの南・ヨークベニマルの東・バス通り上）と一致する。

`src: "gsi_dem"` は既存にない新しい値。`?debug=1` の出典リング（緑=OSM実測/黄=OSM近似/青=住所/赤=概算）の凡例に**緑系の新色を1つ足す**か、既存の緑に含める。凡例文言 `#srcinfo` も合わせて更新すること。

再現性のため `tools/v2-build/build_mapdata.py` の入力データ側にも同じ地点と写真定義を追加し、再ビルドで `preview.html` 相当が再生成できる状態にする。
