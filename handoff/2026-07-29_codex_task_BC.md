## B-2. グラバーが飾りになっている（本番にもある既存バグ）

シート上部の `.detail-handle`（SPAN）は掴めそうな見た目なのに、ドラッグしても高さが変わらない（439px→439px）。`pointerdown`/`touchstart` のハンドラが実装されていない。**この不具合は本番 index.html にも同じくある**が、今回は `preview.html` 側だけ直す。

**実装**

- `.detail-handle` に `pointerdown` → `pointermove` → `pointerup`（`setPointerCapture` を使う）で高さを追従させる
- スナップ点は2〜3段（例: 中＝画面66% / 全＝画面90%）。指を離したら近い方へアニメーションで吸着
- `touch-action: none` をハンドルに当てて、ドラッグ中にページがスクロールしないようにする
- キーボード操作: ハンドルを `role="separator"` + `tabindex="0"` にして ↑↓ でも段を変えられるようにする（`aria-label="お店の詳細の高さを変える"`）
- `prefers-reduced-motion: reduce` の時はアニメーションなしで即座にスナップ
- **横スワイプ（店の送り）と競合させないこと。** ハンドル上のジェスチャだけを縦ドラッグとして扱い、カード本体の横スワイプは今まで通り動かす

# フェーズC — 位置ズレ（④⑤）

## C-1. 何が起きているか（調査済み・実データ）

`GEO.zones` の「5丁目19番かいわい」が同一住所帯の13店を **40px間隔で縦一列に展開**しており、その押し出しが下流の右列店舗まで波及している:

| 店 | 表示y | 真のy(ty) | ズレ |
|---|---|---|---|
| 中山鍼灸接骨院 | 1162.8 | 926.3 | +236px |
| フラワー中山 | 1195.9 | 939.4 | +256px |
| 河村内科外科クリニック | 1238.9 | 962.3 | +277px |
| ウエルシア薬局 | 1282.8 | 1034.6 | +248px |
| たけむらや | 1009.4 | 1009.4 | 0 |

スケールは1px≒1m。真座標では たけむらや(1009.4) と ウエルシア(1034.6) は25px＝約25m差でほぼ真横、フラワー中山(939.4)は たけむらや より**上**。これはあみさんが送ってきたGoogleマップと一致する。現状の表示は上下関係が逆転している。

**現行アルゴリズムの誤り**: これは「重なりを除去しつつ順序を保存し移動量を最小化する」= **MDOR (Minimum-Displacement Overlap Removal)** という既知の問題。現行実装は路線図(schematic)方式で等間隔に並べ直しているが、**順序保存の制約が無い**。schematic map の研究（IJGI 2023・公式路線図の実測分析）では「相対位置の保存が相対長の保存より優先／保存率は約80%」とされており、現行は優先順位が逆になっている。

## C-2. 直し方

**★（星）は実座標に固定し、ラベル側で解決する。**

1. **zone展開を廃止する。** `build_mapdata.py` の zone 縦展開処理をやめ、`x,y` に真座標（現在 `tx,ty` に退避されている値）を入れる。これで位置精度は100%になり、下流の押し下げは消える
2. **ラベル配置を順序保存の最小変位に置き換える。** `layoutLabels()` の `colL`/`colR` 等間隔整列をやめ、1次元の分離制約ソルバ（VPSC相当）にする:
   - 各ラベルの理想位置＝自分の★のy
   - 制約＝隣り合うラベルの間隔 ≥ GAP、**かつ真座標のy順序を必ず保つ**
   - 目的＝理想位置からの移動量の二乗和を最小化
   - 参考実装: WebCoLa の vpsc、PRISM（Graphviz `neato -Goverlap=prism`）。外部ライブラリは足さず、1次元版を自前で書いてよい（数十行で足りる）
3. **物理的に入らない分はズーム依存で間引く。** 13店を縦に並べるには約520px必要で、どう散らしても初期ズームでは全部は入らない。Mapbox/Google と同じく**ラベルを間引く**:
   - 初期ズームでは重ならないものだけ表示。優先度は **こどもの声あり ＞ 公式URLあり ＞ その他**（`symbol-sort-key` 相当）
   - **間引かれた店も★は必ず出す**（位置が正確であることが今回の目的なので、★を消してはいけない）
   - ズームインすると入るようになったラベルから順に出る
   - ラベルが出ていない★をタップしても、今まで通り詳細が開くこと
4. **「ズームすると店名が出ます」を1行案内**として地図の近くに出す（間引きに気づけるように）。既存の `お店一覧` ボタンと検索は今まで通り全店にアクセスできる
