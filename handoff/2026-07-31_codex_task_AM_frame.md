## AM-1 地図の画面に枠を作る（N45 / N46 / N47）

今は `body.map-open #viewport{ position:fixed; inset:0 }` で地図が画面いっぱいに広がり、
その上に操作帯と帰属表示が**重なっている**。地図は自分が 844px あると思って中身を並べるが、
実際に見えるのは 564px しかない。だから上下で切れる。

**直し方: 地図が「自分に与えられた領域」を正しく知るようにする。重ねるのをやめる。**

1. **地図モード専用の上帯（44px）を出す。**
   - `body.map-open` のとき `header` を `visibility:hidden` にするのをやめ、
     地図モード用の細い帯に差し替える（既存 header を作り替えても、専用要素を足してもよい）。
   - 中身: 左に見出し `なかやま商店街マップ`（`<h1>` か `<h2>`。`aria-hidden` にしない）、
     右に **「✕ 通り沿いにもどる」**（44x44px 以上・`#mapbtn` と同じ動作でよい）。
   - 絞り込み中なら見出しの下でなく同じ帯の中に
     `こどもの声 11件` のような小さいバッジを出す（何で絞られているかが地図でも分かる）。

2. **`#viewport` を `inset:0` から、上帯と操作帯に挟まれた領域に変える。**
   - `top:` 上帯の高さ / `bottom:` 地図モードの操作帯の高さ。`height:100dvh` をやめる。
   - こうすると地図の `clientHeight` が本当の見える高さになり、
     中央寄せ・`scrollIntoView`・ラベル配置の計算が全部正しくなる。

3. **地図モードの操作帯を細くする（216px → 56px）。**
   - 地図を見ている間、カテゴリのチップ6個と検索欄は要らない。畳む。
   - 残すのは **「通り沿いにもどる」**と**「お店一覧」**の2つだけ（各44px以上）。
   - 二列モードの操作帯（216px）はそのまま。地図モードのときだけ差し替える。
   - 結果: 地図は 844 − 44 − 56 = **744px = 画面の88%** になる（今67%）。

4. **帰属表示（`footer.credit`）を地図に重ねない。**
   - 今は地図の上に3行64pxで乗っている。OpenStreetMap の ODbL は帰属を求めるが、
     地図の隅の小さな1行＋タップで全文、は OSM 自身も使う正当な形。
   - 地図の**右下**（または左下）に `© OpenStreetMap ほか ⓘ` の1行を出し、
     タップで全文（今の3行＋国土地理院＋商店街振興組合）をシートで開く。
   - **文字は11px以上**（N21の帰属下限）。地図の中身に重ならない位置に置く。
     `#viewport` の外（操作帯の中か上帯の中）に置けば N45 を自動的に満たす。

5. **ズームボタン（`.zoomctl`）を地図に重ねない。**
   - 今は地図の中に浮いていて、店名の上に乗る。
   - 操作帯の中（右端）に移すか、`#viewport` の外の固定位置に出す。
   - 44x44px 以上・画面の下半分（親指が届く範囲・N43）を守ること。

6. **縁の余白。** 地図の中身が上下左右の縁から **6px 以内**に来ないようにする。
   ラベル配置のとき、見える領域（上帯の下端〜操作帯の上端）を境界として使う。

**検証**: `gate.py` の N45 = 0件 / N46 = 0件 / N47 = 0件。
N23（地図が画面の52%以上）と N43（押すものが下半分）も落とさないこと。

## AM-2 カードを押し分けられるようにする（N48）

同じ側で縦に隣り合うカードの隙間が **0px** で、8枚が1枚の板に見える。
ボスの「ボタン単一が押しにくい」はこれ。

**先に知っておくこと（計算済み）**:
実座標比例のまま隙間8pxを取ろうとすると **26.5 px/m** 必要（全長37,000px）。
理由は「ん daccha とこや」と「中山不動産」が **南北2m差**の隣同士だから。
**縮尺を上げても解決しない。押し出しは必ず要る。** 目的は押し出しを無くすことではなく、
**押し出したことを見えるようにしたうえで、押し分けられる隙間を作ること**。

**直し方**:

1. 縦の縮尺を **1.0 px/m → 1.3 px/m** に上げる（`T(y)=34+(y−55)×1` の係数）。
   - 二列の高さは 1929px + 押し出し。今は衝突補正で既に 2026px あるので、
     **スクロール量はほぼ変わらない**。
   - 位置関係（東西・南北の順序・相対距離）は保たれる。縮尺が変わるだけ。

2. 衝突補正の目標を「重ならない」から **「隙間8px以上」** に変える。

3. 押し出しで実位置から **12px 超**ずれたカードには、
   カードの通り側の辺から通りへ向かって **短い横線**を引く（地図の引き出し線と同じ考え方）。
   - 線の先端が実際の南北位置。これで「ずらして並べてある」ことが読み取れる。
   - 線は `pointer-events:none`。カードの押せる範囲を邪魔しない。

4. カードを「独立した粒」に見せる。
   - 角丸を 15px → 20px 前後。
   - 影を少し強める（今 `1px 2px 0 rgba(92,67,39,.2)`）。
   - 隣り合うカードの境界線が2本並んで4pxの帯に見えるのを避ける。

**検証**: N48 = 0件。N41（並び順）・N42（向かい合わせ48px以内）を**落とさないこと**。
N42 は縮尺1.3倍で差も1.3倍になるので、今の最大37.1px が 48px を超えないか必ず確認する。
超えるなら、向かい合うペアは押し出しの向きを揃えて差を吸収する。

## AM-3 絞り込みを1画面で見渡せるようにする（N49）

「こどもの声 11件」と出るのに、画面には0〜1件しか無い。
該当店が実座標のまま 2026px に散っているため。**これが「操作間が悪い」の一番の中身。**

**直し方: 絞り込み・検索が効いている間は「詰めモード」にする。**

- 該当する店だけを、**東西の列と南北の順序を保ったまま**、上から等間隔（隙間8px）で詰める。
- 通りの帯（`.strip-road`）はそのまま出す。列の意味（西/東）は変えない。
- 絞り込みを解除したら、元の実座標比例に戻す。
- 詰めモードの間は上に `こどもの声 11件` と出す（今は検索欄の右にはみ出して見える）。
- 「通りから少し離れた場所」の節も同じ扱いで、該当があるときだけ出す。

位置関係は変えていない: どっち側か、どっちが北か、は完全に保たれる。
変わるのは**間隔だけで、絞り込んでいる間だけ**。

**1件だけ当たったときに詳細シートを自動で開くのをやめる**（今は `focusShopOnMap` を呼び、
地図が閉じていると二列が真っ白になる）。1件でも詰めモードで1枚出し、光らせるだけにする。
詳細は利用者が押したときに開く。

**検証**: N49 = 0件（該当が6件以上なら画面に6件以上、6件未満なら全部）。

## AM-4 探しそうな言葉で店が引けるようにする（N50）
