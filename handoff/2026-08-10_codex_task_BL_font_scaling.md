# BL: 端末の文字を大きくしても崩れないようにする

商店街の担当者（あみさん）から「スマホで拡大すると文字が大変なことになってる」と指摘が来た。
実測したところ **ブラウザのピンチ拡大と地図の＋は無傷**で、犯人は **Android/iOS の「文字の大きさ」設定**だった。
`gate.py` に文字サイズの総なめ (150% = 24px / 200% = 32px × 320x568・390x844) を足したので、
**いまの本番は FAIL(28件) になる**。それを 0 にするのが今回の仕事。

## 触ってよい / いけない

- 触る: `tools/v2-build/template.html`（必要なら `tools/v2-build/build_mapdata.py`）
- **触らない: `tools/v2-build/gate.py`**（検査は私が持つ。合否の基準を動かして通すのは不可）
- **触らない: `index.html` / `v2.html`**（生成物。`python tools/v2-build/build_mapdata.py` で作る）
- **触らない: `mapdata.json` / `official_details.json`**（店名・住所・電話などの中身は
  クライアント確認が要る。見せ方＝文字サイズ・折り返し・配置だけが裁量）

## 何が起きているか（根本原因・実測済み）

`header` は縦を px で決め打ちしていて、中の見出しは端末の文字設定で伸びる:

```css
@media(max-width:759px) and (orientation:portrait){
  header{ flex:0 0 44px; height:44px; overflow:hidden; }   /* 743行あたり */
}
@media(orientation:landscape) and (max-height:480px){
  header{ flex:0 0 38px; height:38px; ... overflow:hidden; } /* 795行あたり */
}
header h1{ font-size:1.2rem; }          /* 200%端末では 38.4px になる */
.shop-total-summary{ font-size:max(14px,.875rem); }
```

44px の箱に 105px の中身が入るので、見出しの上下が刈られ「全60店」が消える。
`overflow:hidden` なので **切れたことが誰にも見えない**のが一番悪い。

この作りの方針自体は既にファイルに書いてある（88-92行）:
**操作まわり（チップ・ボタン・見出し）は頭打ちにする / 本文（店名・住所・詳細）は端末設定に追従させる。**
チップだけがその扱いを受けていて、見出し・検索欄・詳細の操作ボタンが取り残されている。
**新しい方針を作らず、この二段構えを残りへ広げること。**

## 決め方の指針（迷った時）

- **操作まわりは頭打ち**にする。チップと同じく `clamp(下限, Nrem, 上限)` で止める。
  対象＝`header h1` / `.shop-total-summary` / `#q` / `.detail-nav button` / `#searchstatus`。
- **箱は伸びられるようにする**。`height:44px` のような決め打ちは `min-height` に変え、
  `overflow:hidden` で黙って刈らない。ただし `--controls-h` / `--map-head-h` の
  予算とつながっているので、一覧・地図の高さが痩せていないか gate で確かめること
  （N23「主の内容が画面の62%以上」が床）。
- **店名は固有名詞なので途中で割らない**。200%で 320px 幅に収まらない名前
  （「カーブス アクロスガーデン中山」等）は、名前の文字だけ上限をつけて縮めてよい。
  **名前を削る・省略記号でごまかすのは不可**（何の店か分からなくなる方が害が大きい）。
- 中身（店名・住所・電話・座標）は一文字も変えないこと。

## 合格条件

1. `python tools/v2-build/build_mapdata.py` が通り、`index.html` / `v2.html` が更新される
2. `python tools/v2-build/gate.py --target index.html` が **PASS（違反0件）**
   — N1〜N59 全部。文字24px/32px の行も含む
3. 「歩ける店」が **60/60** のまま
4. JSエラー 0

結果は `result.txt` に、直した箇所と最後の gate 出力の末尾10行を貼ること。
