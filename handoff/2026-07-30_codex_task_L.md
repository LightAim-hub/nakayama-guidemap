# Codex 作業指示 L — 既定ズームを 0.92 px/m に上げ、通りと店を完全に分ける

前提: Task K 完了後のコミット。

## ボスの判断（2026-07-30）

概観ズームで「通りとして読める帯」と「真の位置の店」は両立しません（算術的に）。
既定ズーム 0.4487 px/m では、通りとして読める幅（12px）は地図空間で 26.7m を占めるのに対し、
実際の店の離れは 6.6〜20m です。**ボスは「最初から寄せて開く。通りと店を完全に分ける」を選択しました。**

```
既定ズーム 0.4487 px/m → 0.92 px/m
```

この倍率では実幅13mがちょうど12pxになるので、**幅を偽らずに**通りが読めます。
帯の半幅 6.5m + ★半径 4.0m = 10.5m 以上離れた店は帯に一切かかりません。

代償（ボス了承済み）: 最初の画面に入るのは 26/60 店。残りはスクロール・ズームアウト・「お店一覧」。

## L-2 ズームアウトを壊さない

`+` `−` の操作で全体（canvas 1291×1738 全体）まで引けること。
**Task J で入れた道路の画面px床は維持**します（0.92 px/m 未満で効く安全網）:

```
描画幅 = max(実幅[地図単位], 床[px] / pxPerMeter)
床 = main 12px / major 11px / mid 8px / minor 5px
★の画面px = clamp(6.0, 0.60 × 描画された main 道路のpx, 11.0)
```

0.92 px/m では実幅が床とちょうど同じ（13m × 0.92 = 11.96px）なので、**既定ズームでは
床が効かず実幅で描かれます**。これがボスの言う「偽りなし」です。
