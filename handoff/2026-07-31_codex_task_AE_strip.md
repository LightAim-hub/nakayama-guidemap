## AE-1 通り沿いの二列表示（主役）

```
  ← 西側          中山バス通り          東側 →
 ─────────────────────────────────
  たけむらや    │              │  ウエルシア薬局
                │   ● 中山4丁目 (信号)    │
  柏屋 🔵      │              │  河村内科外科クリニック
                │              │
  Double Egg4丁目│              │  フラワー中山 🔵
```

- **縦の位置は実際の y に比例**させること。向かい合わせが同じ高さに来るのが要件
  （柏屋 ⇔ 河村内科外科クリニック は南北差0m = 真向かい）
- 同じ側で12m以内の10組は潰れるので、**最小の行間**を設けてずらす。
  ずらしても**順番は絶対に入れ替えない**
- 北が上・南が下
- 中央の帯は「中山バス通り」。**信号13基を実際の y の位置に置く**
  （歩いている時、信号は一番確かな現在地の手がかり）
- こどもの声の店には印を付ける
- 各行はタップで既存の詳細シートを開く

### DOM の約束（採点表がこれを見ます）

```html
<div id="strip">
  <div class="strip-row" data-i="12" data-side="west" data-y="431.5">…</div>
  <div class="strip-signal" data-y="512.0">…</div>
</div>
```

- `data-i` = `GEO.shops` の添字
- `data-side` = `west` / `east`
- `data-y` = その店（信号）の真の y（地図座標）
- 離れた店の節は `<div id="stripfar">` に、同じ `.strip-row` で入れる

## AE-2 離れた店は別の節にする

通りから60m超の20店は、二列の下に **「通りから少し離れた場所」** としてまとめる。

- 各行に**通りからの距離と方向**を出す（例: 「西へ約250m」）
- 通り沿いの40店と混ぜない（混ぜると位置関係が嘘になる）

## AE-3 操作を親指の届く下へ

いま検索とカテゴリは画面の**上**にあります。片手で歩きながら押せません。

- **検索とカテゴリを画面の下**（親指の届く範囲）へ移す
- 画面の上は見出しだけ
- 押すものはすべて **44px以上**（N20）・**互いに8px以上**（N31）
- カテゴリ6個は縦向き・横向きとも**全部見えること**・「こどもの声（11店）」は先頭

## AE-4 地図は残す

- 「地図で見る」ボタンで、いまの地図を全画面で開く
- 地図側の作り（★・ラベル・引き出し線・ピンチ・信号）は**そのまま**。
  ゲート N1〜N39 は地図側で引き続き効きます
- 地図から二列表示へ戻れること

- **座標を1つも変えない**（位置の正しさは検証済みの資産）
