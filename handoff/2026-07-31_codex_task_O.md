## O-1 カテゴリを全端末幅で全部見せる（N22 = 0）★最優先

## O-3 拡大したら単一ボタンで押せるようにする（N24 = 0）

いま `nearby(s)` は **22m 固定**で、ズームしても縮みません:

```
既定 0.92px/m → 22m = 20.2px   チューザーが出る店 21件
歩き 2.0px/m  → 22m = 44.0px   チューザーが出る店 21件  ← 拡大しても減らない
最大 5.0px/m  → 22m = 110px    チューザーが出る店 21件  ← 店は42px離れているのに出る
```

**半径を「画面px相当」にしてください**（例: 画面20px ÷ 現在の pxPerMeter）:

```
既定 0.92px/m → 21.7m   21件  （物理的に不可避。最短の2店は8.5m = 7.8px、指は約44px）
歩き 2.0px/m  → 10.0m    8件
最大 5.0px/m  →  4.0m    0件  ← 全店が単一ボタンで押せる
```

- **合格: 歩きズーム(2.0px/m)でチューザーが出る店が10件以下**
- 概観ズームでチューザーが出るのは正常です（指が2店を覆うため）。無理に消さないこと
- チューザーが出たとき、狙った店が必ず選択肢に入ること（現在も成立・壊さない）
- チューザーの選択肢は44px以上を維持
