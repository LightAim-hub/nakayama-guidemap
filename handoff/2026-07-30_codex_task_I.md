## I-1 建物を座標の正本にする（最優先・これが本体）

「店は建物の中にある」を**ハード制約**にする。

1. `buildings_raw.json` を builder に読み込み、既存 `project()` で canvas 座標のポリゴンにする
2. 各店について:
   - 建物ポリゴンの**内側にいる** → そのまま（動かさない）
   - **外にいる** → 最も近い建物ポリゴンの内側へ寄せる。寄せ先は重心でなく**「元の点から最短で入る内部点」**（境界から2m以上内側）
3. 移動時に壊してはいけない制約（順に優先）:
   - **どの道路の帯の内側にも入らない**（中心線からの距離 ≥ その道路の塗り幅/2 + 2m）
   - バス通りの**東西の側**が変わらない
   - **南北の並び順**が変わらない（真座標の順序）
   - 同一住所5組の**上下と14m分離**を維持
4. **除外6件**（建物が存在しない敷地。動かさない）:
   `たきみち公園` / `なかやまとびのこ公園` / `中山山の神公園` / `中山小学校` / `中山中学校` / `中山ドライブスクール`
5. `商店街モニュメント`（住所が存在しない物体・現在 mid道路から1.7m）は道路の帯の外へ出すだけでよい

**合格条件**
- 建物の中にいる店 = **54/54**（除外6件を除く全店）
- どの道路の帯の内側にもいる店 = **0**
- 東西の反転 = 0 / 南北順の反転 = 0 / 同一住所ペアの破れ = 0

## I-2 ★とラベルを画面px固定にする

★が19.3m固定である限り、店を建物に入れても**絵が道路にかかる**。ズームでも比率が変わらないので、これはサイズ設計の問題。

1. **★のサイズを画面px固定にする**: `applyZoom` で `use.star` の scale を `targetPx / (pxPerMeter * 20)` に更新（20 = `#starShape` の基準幅）。目標 = 通常 **11px** / アンカー店 14px。**下限6px（現行の実測最小値）を割らない**
2. これで拡大時に★の地図空間の見かけが縮み、道路の横に正確に収まる。**Task H の8m微小変位は不要になるので撤去**（I-1の建物内配置を壊すため）
3. **ラベルも同様に画面px固定**: 通常 11〜12px / アンカー店 14〜15px（`FS` を `applyZoom` で再計算）
4. ラベルの引き出し線が**交錯しない**こと。交錯するなら、そのラベルは非表示にしてよい（優先度: こどもの声あり ＞ 公式URLあり ＞ その他）。**★は60件すべて必ず表示**

**合格条件**
- ★の画面サイズ: 全ズームで 6px 以上・デフォルトで 11±1px
- **★の絵が道路の帯にかかる店 = 0（2px/m 以上のズームで）**
- ラベルの bbox 交差 = 0 / 引き出し線の交差 = 0
- ラベルの実表示 = デフォルトで 11px 以上
